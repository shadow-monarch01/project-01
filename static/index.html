About AI Hiring System

This system detects unverbalized bias in AI-driven hiring decisions using controlled counterfactual perturbation and evaluates Explanation Faithfulness Scores (EFS).

Core Metrics:

  • Explanation Faithfulness Score (0-100): Quantifies whether the model truthfully explained the real causal drivers behind its decision.
  • Statistical Significance: McNemar (Binary), Chi-Square (Multiclass), Paired t-test (Regression).
  • Mitigation Feedback Loop: Applies prompt constraints to empirically reduce bias disparity.
